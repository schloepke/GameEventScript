# Portable text semantics

> [!IMPORTANT]
> **Structural draft.** This document owns the normative text and Unicode contract but is not yet complete.

## Scope

This specification defines strict UTF-8 input, BOM handling, logical newlines, portable whitespace, ASCII name grammars, Unicode-scalar runtime operations, source columns, byte offsets, normalization policy, and scalar-ordinal ordering.

Language syntax belongs to [Language](../Language.md). Source-map encoding belongs to [Binary format](../BinaryFormat.md).
