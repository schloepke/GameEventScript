Struct GesBitReader

Reads values of 0 to 64 bits from untrusted data in the bit order of the schema wire format: least significant bit first, bytes in Little Endian order. It knows no schema; generated schema code and GesSchemaReader build on it. Reading allocates nothing.

Remarks

Every read checks the end of the data. Reading past it fails with wire.truncated, or with wire.limitExceeded when the byte limit ends before the data does. The path passed to a read names the field in that error.
