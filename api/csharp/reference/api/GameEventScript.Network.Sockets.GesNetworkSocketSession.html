Class GesNetworkSocketSession

Carries one GesNetworkConnection over a TCP stream, a WebSocket or UDP. Background tasks only move bytes: the host calls Receive(long) and Transmit(), or Update(long) for both, on its own thread, which feed received bytes into the connection, advance it and hand its packets to the sender. The connection is touched only by the host thread. As an IGesNetworkLink it is the transport of an end.

Dispose()

Releases the socket. When the connection is closed and its last packets are handed to the sender, they are still written, once the transport opened if it still opens, and the transport ends in order, within the connection's timeout; otherwise both background tasks stop at once without sending anything more.

public void Dispose()

Receive(long)

Feeds the received bytes into the connection, advances it to now and reports the end of the transport. Call it on the host thread. While CanReceive is false the bytes wait, and once the queue of received chunks is full the socket stops reading, so the peer's sending slows down.

public void Receive(long now)

Hands every packet the connection has due to the sender. While the transport still opens the packets wait for it. Call it on the host thread.

Update(long)

Feeds the received bytes into the connection, advances it to now, reports the end of the transport and sends every due packet: Receive(long) followed by Transmit(). Call it on the host thread, then take the connection's events.
