# Portable diagnostics specification

> [!IMPORTANT]
> **Structural draft.** This document owns the normative diagnostic contract but is not yet complete.

## Scope

This specification defines diagnostic phases, stable ASCII codes, severity, symbol context, source locations, Program and handler context, propagation through public APIs, observer reporting, and portability requirements.

Diagnostic text is explanatory and is not a stable comparison key. Source position rules belong to [Text semantics](Semantics/Text.md), while API delivery belongs to [Public API](PublicApi.md).
