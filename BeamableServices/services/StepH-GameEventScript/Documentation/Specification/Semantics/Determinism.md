# Portable determinism semantics

> [!IMPORTANT]
> **Structural draft.** This document owns the normative deterministic behavior contract but is not yet complete.

## Scope

This specification defines seeded PRNG state transitions, bounded sampling, Binary64 draws, nested random scopes, structural equality, stable sorting, collection and map iteration, ranges, and equal-priority dispatch ordering.

Numeric edge behavior belongs to [Number semantics](Numbers.md), text ordering to [Text semantics](Text.md), and host dispatch state transitions to [Host runtime](../HostRuntime.md).
