Accepts TCP, WebSocket or UDP clients for a server. A background task accepts sockets and, for WebSocket, answers the HTTP upgrade, or for UDP reads the shared socket, validates unknown addresses and routes each datagram to its client; the host takes each ready client with Accept(long) on its own thread. At most 64 clients wait or upgrade at once, accepting pauses while they do, and one IP address holds at most 8 of them; its further sockets are closed. As an IGesNetworkAcceptor it accepts the clients of a server end.

ListenUdp(IPEndPoint, GesBoundNetwork, GesNetworkOptions)

Starts receiving UDP datagrams for server connections of the datagram transport. Datagrams of an unknown address pass through address validation with a random key of this listener; a client whose hello carries a valid cookie becomes ready for Accept(long). The datagrams of a known address go to its session.
