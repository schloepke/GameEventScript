CheckedExclusivity

Gets or sets whether generated Swift classes keep the dynamic exclusivity checks of their stored properties. By default they mark them @exclusivity(unchecked), which halves the time of reading and writing; overlapping accesses to one record, such as passing a list inout while the record reads into it, are then undefined instead of a trap. C# has no such checks, so this does not change C# output.

public bool CheckedExclusivity { get; set; }

Documents

Gets or sets whether generated model roots also read GES document text: each root a FromDocument (Swift init(document:)) that requires the header :Schema(:Name), checks the document against the embedded schema sources, applies defaults and converts, and one type per generation that reads any root by its header, Document inside the namespace and ModelDocument without one. It includes Values. The code reads text and does no file I/O. Only model generation takes it.

ExtendNamespace

Gets or sets the leading part of the Swift Namespace that another generation of the module declares, or null for none, the default. This generation extends it instead of declaring it again: with the namespace Game.Panels and Game here it writes extension Game { enum Panels { … } }, and with Game for both it writes extension Game { … }. It must be a leading part of the namespace, else generate.usage. Wire code with Models extends the part it shares with the models' namespace on its own. C# merges namespaces, so C# generation rejects it with generate.usage.

public string? ExtendNamespace { get; set; }

Models

Gets or sets the namespace of the model code that wire code shares types with, or null for none, the default. With it, wire code uses that namespace's packed types instead of declaring its own, so a List of them is one array in both, and converts each wire record directly to and from the model of the same schema that a model root of any group reaches. An empty string is the global namespace. Only wire generation takes it.

SchemaSet

Gets or sets the name of a schema set type to declare in the namespace, or null for none, the default: a C# static class or Swift enum that holds the embedded schema sources parsed once, the parameter values of this generation, a hash over both and the binding of schemas, networks and documents against them. The generated conversions, network bindings and document readers then use it instead of a private helper, and other generations share it through UseSchemaSet. It must be an identifier; it excludes UseSchemaSet.
