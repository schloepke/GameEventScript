Class GesSchemaGenerator

Namespace
GameEventScript.Generator
Assembly
GameEventScript.Generator.dll

Generates code and layouts from schemas at build time. Every type reached from the roots is bound once with the given parameters, so a type that several roots share appears once. The generator belongs to build tools and is never part of a game.

Generate(GesSchemaSet, IReadOnlyList<string>, GesSchemaParameters, GesSchemaGenerateOptions)

Generates code for the roots and every type they reach: a type per schema that writes and reads its records with the bytes, error codes and paths of GesSchemaWriter and GesSchemaReader. Every port writes identical text for identical schemas, parameters and options.

public static string Generate(GesSchemaSet set, IReadOnlyList<string> roots, GesSchemaParameters parameters, GesSchemaGenerateOptions options)

Parameters

set GesSchemaSet

The schemas.

roots IReadOnlyList<string>

The schemas to generate, in the order the header names them.

parameters GesSchemaParameters

A value for every parameter the roots reach; they become constants of the code.

options GesSchemaGenerateOptions

The language, namespace and visibility.

Returns

string

The source text, ending with a line break.

Exceptions

ArgumentException

A root is not declared.

GesSchemaException

A root cannot be bound, for example because a parameter has no value.

GesGeneratorException

No root is given, the namespace is invalid, two generated names collide, or a reached type cannot be generated yet.

Layout(GesSchemaSet, IReadOnlyList<string>, GesSchemaParameters)
