A deliberate, portable runtime fault that an extension function, native handler, external-type constructor, or IGameEventScriptExternalValue implementation throws to report a defined failure. It ends the current handler with a diagnosable runtime error instead of silently evaluating to nothing; the host remains reusable for subsequently enqueued messages, as for any other runtime error.

Remarks

This is distinct from an unanticipated exception raised by a bug in the same callback: that case is reported as RuntimeExtensionCallFailed, RuntimeExternalConstructorFailed, RuntimeExternalFieldAccessFailed, or RuntimeNativeHandlerFailure and never requires this type.

Parameters

code string

A stable code in the caller's own namespace, for example "myExtension.outOfStock". It must not be empty or consist only of whitespace. It must not start with the reserved "runtime." prefix used by internally raised runtime diagnostics.

message string

A human-readable explanation. It may change and must never decide portable conformance.

symbol string

An optional symbol identifying the failing construct.

innerException Exception

An optional original cause. It is never part of the diagnostic's normative fields; when present, it is rendered into TechnicalDetails only, which is non-normative logging text.

Exceptions

ArgumentNullException

Thrown when code or message is null.

ArgumentException

Thrown when code is empty, consists only of whitespace, or starts with the reserved runtime. prefix.
