01

Messages connect the pieces

Handlers react to named messages and emit new ones. Your application supplies native actions, data and the starting event.

02

State stays with you

Script values are immutable. Your application owns persistent state and decides what scripts can see through explicit native bindings.

03

A shared contract

C# and Swift implement the same language and portable program format, checked against a shared Markdown conformance corpus.
