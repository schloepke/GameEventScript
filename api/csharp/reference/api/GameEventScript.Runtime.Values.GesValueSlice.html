Read-only view of a contiguous run of values, for example the elements of a List returned by AsList(). The view borrows its storage without copying; indexers return read-only references into that storage.

GetAsBoolean(int)

Converts the argument at index to a Boolean, as AsBoolean() does. A Boolean is returned unchanged; numbers, quantities and Percentages are true when nonzero; a Vector or Point is true when any component is nonzero; a Text is true only when it is true (ASCII case-insensitive) or 1. Every other kind, including Nothing, Tag, Dice, Bytes and the collections, yields false.

GetAsInteger(int)

Converts the argument at index to a signed 64-bit integer, as AsInteger() does. Integer values are returned unchanged and Dice yield the sum of their rolls; Boolean yields 1 or 0; binary64 numbers and Percentage ratios are truncated toward zero and saturated to the Int64 range. Every other kind, including Nothing, yields 0. A quantity's unit is ignored, so the number is read in the value's own unit.

GetAsNumber(int)

Converts the argument at index to a binary64 number, as AsNumber() does. Integer values and Dice sums are converted to binary64 and may round beyond 2^53; binary64 numbers are returned unchanged; a Percentage yields its ratio, so 50% is 0.5; Boolean yields 1 or 0. Every other kind, including Nothing, yields NaN. A quantity's unit is ignored, so the number is read in the value's own unit.
