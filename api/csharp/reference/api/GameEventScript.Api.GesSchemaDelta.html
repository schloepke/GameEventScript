Class GesSchemaDelta

Namespace
GameEventScript.Api
Assembly
GameEventScript.Runtime.dll

Converts between full records of a schema and deltas against a baseline, the full record the receiver already holds. Both directions compare wire values and allocate nothing on success. Data is untrusted: every limit is checked, and invalid data fails with a GesWireException.
