Game Event Script

Namespace GameEventScript.Api

Classes

GameEventScriptHost

Serial message host for native handlers and optional GameEventScript programs. The portable core performs no synchronization and creates no worker threads.

GameEventScriptMessage

Represents a message used within the Game Event Script system. This message serves as a fundamental unit for communication, allowing for event-driven execution between components, scripts, and handlers.

GameEventScriptProgram

The immutable, reusable parsed representation of one .gesb V1 program, produced only by the Compiler or by Read(ReadOnlySpan<byte>, GesProgramReadOptions?), both of which run the complete program validator before returning it.

GesBinaryFormat

Fixed constants of the canonical little-endian .gesb V1 container framing.

GesBoundNetwork

A network bound to parameter values. Immutable; it can be shared between threads and connections.

GesBoundSchema

A schema, message or message set bound to parameter values. Immutable; it can be shared between threads.

GesBuildMetadataSegment

The immutable optional BuildMetadataSegment (section 0x0030), which names the producing compiler. Runtime behaviour never depends on it.

GesCompileException

Represents an exception that occurs during the compilation process of a Game Event Script. This exception is specifically used to signal issues detected during the parsing or validation phase of script compilation.

GesCompileOptions

Represents a game event script compile options.

GesContext

Host-owned context shared by native and GameEventScript handlers.

GesDebugSymbolsSegment

The immutable optional DebugSymbolsSegment (section 0x0020), which names script parameters and locals by register and code range. Runtime behaviour never depends on it.

GesDeclaredExternalTypeCatalog

Immutable external type catalog built from a fixed list of definitions.

GesDiagnostic

A portable diagnostic of a source, binary, linking or runtime failure. Phase and Code identify it; the optional fields add structured context and are absent when unknown.

GesDiagnosticCodes

Defines the stable diagnostic code strings; a code is compared together with its GesDiagnosticPhase, never through the message text.

GesDocument

An immutable GES document: a Map or Record root with an optional schema reference, read from and printed to human-editable .gesd text. Comments and layout are not part of a document.

GesDocumentException

GES document text is invalid or exceeds a fixed literal parsing limit.

GesDocumentFormat

Layout options for printing GES documents and values. Layout is a recommendation: every printed document reads back to an equal document, while indentation, line breaks and numeric spelling may differ between implementations.

GesDocumentSchema

The schema reference of a GES document. It is a reference only: GES neither loads schema files nor validates documents against record definitions.

GesDynamicLinkException

Thrown when a Program cannot be linked to a host, for example because of a missing extension or external type constructor or an exceeded register or call-depth limit. It carries one or more link-phase diagnostics.

GesExtensionCall

Reusable call-scoped adapter passed to Invoke(GesExtensionCall): it lends the arguments, the host context and its random generator, and receives one result. The last setter call before the callback returns decides the result; without one the result is Nothing. The call must not be retained.

GesExtensionFaultException

A deliberate, portable runtime fault that an extension function, native handler, external-type constructor, or IGesExternalValue implementation throws to report a defined failure. It ends the current handler with a diagnosable runtime error instead of silently evaluating to nothing; the host remains reusable for subsequently enqueued messages, as for any other runtime error.

GesExtensionReference

Represents an immutable normalized extension name, function name, and ordered argument signature.

GesExternalTypeConstructorCall

Reusable call-scoped adapter passed to Invoke(GesExternalTypeConstructorCall): it lends the arguments and receives the constructed value. It must not be retained beyond the callback.

GesExternalTypeConstructorDefinition

Immutable declarative signature of one external type constructor: the type it builds and its parameters.

GesExternalTypeConstructorReference

Represents an immutable normalized external type name and constructor argument signature.

GesExternalTypeDefinition

Immutable declarative description of one external type: its name, ordered unique fields and ordered unique constructor signatures.

GesExternalTypeFieldDefinition

Immutable description of one external type field: its name and declared type. Field values are converted to the declared builtin type before a script sees them; Nothing stays Nothing.

GesExternalTypeParameterDefinition

Immutable description of one external constructor parameter: its argument label, which must name a declared field, and its declared type. Arguments are converted to the declared builtin type before the constructor sees them; Nothing stays Nothing.

GesFatalRuntimeException

Base class of exceptions that carry a runtime GesDiagnostic and end the current handler with that diagnostic. The exception message is the diagnostic's message.

GesFloatRange

An immutable binary64 range descriptor; terms are computed lazily.

GesGeometryLibrary

The standard geometry library: the external types :Box, :Poly and :Disc over GesBox, GesPoly and GesDisc, and the extension functions :geometry.*, so that hosts and scripts compute alike. A host that wants it passes Catalog(IGesExternalTypeCatalog?) to the compiler and ExternalTypes(IGesExternalTypeRegistry?) and Extensions(IGesExtensionRegistry?) to the host, each in front of its own catalog or registry, which resolves what the library does not.

GesHostBuilder

Configures and creates independent serial GameEventScriptHost instances.

GesIntegerRange

An immutable signed-64 range descriptor. Terms are computed lazily without binary64 conversion.

GesLiteralLimitException

Literal recognition outside a Host exceeded one of its fixed protection limits.

GesMessageArguments

Ordered message arguments. Argument names are part of the message signature and therefore preserve source order.

GesMessageFormatException

Invalid, unsupported, or over-limit portable message/value JSON.

GesMessageSignature

Represents a message signature used in GameEventScript to uniquely define the structure of a message, including its name and ordered parameter list. This class provides utilities to normalize, validate, and match message signatures accurately.

GesNetwork

A network declaration: the routes of one client–server pair. Immutable; it can be bound any number of times.

GesNetworkRoute

One route of a network. Immutable.

GesOpaqueSection

An optional section the reader retained without interpreting it under PreserveAll: an unknown optional section, or a known optional section with an unsupported version or compression. The writer re-emits it unchanged after the known sections.

GesPoly

A closed polygon in the plane z = 0, without a unit: its points in order, the last connecting to the first. A polygon is valid with at least three finite points in the plane, no edge of zero length, no two edges that cross or overlap, and an area other than zero; the operations of an invalid one give null, as GES operations give nothing for a domain failure. Scripts see it as the external type :Poly of GesGeometryLibrary.

GesProgramBuilder

Compiles source text into immutable Programs using the optional GameEventScript.Compiler package.

GesProgramBuilderEntry

Adds the Program builder entry point to GameEventScriptProgram when the Compiler package is referenced.

GesProgramFormatException

Thrown when a .gesb image or a program is malformed, unsupported, exceeds read limits, or violates a program invariant. Raised by reading, writing, size calculation, validation and Host.Load.

GesProgramInstance

Represents one host-local loading of a reusable immutable program.

GesProgramReadLimits

Resource bounds that Read(ReadOnlySpan<byte>, GesProgramReadOptions?) checks before allocating. Exceeding a count limit fails with TooManyEntries, a byte limit with the code named on the property; a limit outside its supported range makes Read throw ArgumentOutOfRangeException.

GesProgramReadOptions

Options for Read(ReadOnlySpan<byte>, GesProgramReadOptions?).

GesQuantityUnits

Names, spellings and arithmetic of the closed set of GameEventScript quantity units.

GesRandomGenerator

A sealed class that provides mechanisms for generating random numbers or values, either through a pseudo-random number generator or a predefined sequence of values. This class is useful for scenarios where deterministic or non-deterministic random value generation is required, especially in game event scripts.

GesRuntimeLimits

The safety limits of one host: work, nesting and collection sizes per handler and the queue of the host. They bound time and stack use, not memory (specs/HostRuntime.md). Exceeding most limits stops the active handler with a structured runtime-limit observation; the remarks of each property state its exact outcome.

GesSchema

The immutable description of one schema, message or message set of a GesSchemaSet. It can be shared between threads and bound any number of times.

GesSchemaAxisInfo

The limits of a numeric axis of a Point, Vector, Box, Poly or Disc, or of the radius of a Disc.

GesSchemaComputedFieldInfo

A field written computed by: a value derived from the other fields that is never encoded or read from a document.

GesSchemaConstantInfo

A constant of a schema, declared as let name be value: never encoded, part of the hash, and generated as a static member of the schema's types.

GesSchemaDefaultEntryInfo

A field that a record literal default names, with its value.

GesSchemaDefaultInfo

The value a field takes when a value or document leaves it out, declared with default; the wire always carries the field.

GesSchemaDelta

Converts between full records of a schema and deltas against a baseline, the full record the receiver already holds. Both directions compare wire values and allocate nothing on success. Data is untrusted: every limit is checked, and invalid data fails with a GesWireException.

GesSchemaDocument

A GES document read against the schema its header names, as generated models read their documents: the header :Schema(:Name) names one of the expected schemas, the document passes the schema's check, and its entries are the plain value that a model converts. Errors carry their position and field path.

GesSchemaDump

Makes binary data readable through a bound schema.

GesSchemaException

A schema source or a binding that breaks a rule. Callers branch on Code, a stable schema.* code; the message is informative text.

GesSchemaFieldInfo

A field of a schema or an argument of a message.

GesSchemaParameterInfo

A parameter that a declaration reaches and every binding must supply.

GesSchemaParameters

The parameter values of one binding.

GesSchemaSet

Validated schema sources. A set is immutable and can be bound any number of times, also with different parameter values within one session.

GesSchemaTakeInfo

The fields a schema takes from another with with.

GesSchemaType

The type of a field, or one alternative of a union.

GesSchemaValues

The convenient path between GES values and the wire, for rare data. A Record or Map encodes by field name, and fields without a schema entry, such as computed fields, are not transmitted. Only a Map that selects a union alternative must have a field for each of its keys. Time-critical code uses GesSchemaWriter and GesSchemaReader.

GesSourceArchiveEntry

One embedded compiler input in the GesSourceArchiveSegment: the exact logical source as UTF-8, without the original byte order mark or file encoding.

GesSourceArchiveSegment

The immutable optional SourceArchiveSegment (section 0x0022), which embeds the compiler inputs.

GesSourceLocation

Represents a specific location in a source file or module for the GameEventScript compiler. This class is used to pinpoint the origin of a particular piece of code or error within a source context.

GesSourceMapSegment

The immutable optional SourceMapSegment (section 0x0021), which maps code addresses to source byte ranges. It is useful without an embedded GesSourceArchiveSegment; when both are present they must agree.

GesSourceMapSource

Describes one compiler input in the GesSourceMapSegment. All offsets and lengths count bytes of the logical UTF-8 source, not UTF-16 code units.

GesSubscription

Represents one host-local native message subscription.

GesSystemClock

The system monotonic clock, measured from the moment the instance was created. Reading allocates nothing and is unaffected by changes of the wall-clock time. An instance may be shared between hosts and network ends that use one timeline.

GesVirtualClock

A virtual clock for deterministic simulation and tests: its time changes only through Advance(long). Not thread-safe; one caller at a time, like the host or end that reads it.

GesWireException

A value that cannot be encoded, or data that is not a valid encoding. The error names the field path and holds no value from the data, so it can be logged safely.

GesWireRules

The value rules of the schema wire format over plain operands: Text and tag validity, the exact quantization of a step p / 10^k and wrapping. Generated schema code calls them with constant operands, and the interpreted writer and reader use the same rules, so both encode identical bytes.

Structs

GesBindingSegment

The immutable BindingSegment (section 0x0004): the program's exported handlers and callables, imported extensions and external types, outbound message signatures and Record constructors, in encoded order.

GesBindingSegment.Entry

One immutable binding record. In .gesb the argument-name and tag lists are UInt16IndexListSegment indices; this model holds their resolved elements, which are string-constant indices.

GesBitReader

Reads values of 0 to 64 bits from untrusted data in the bit order of the schema wire format: least significant bit first, bytes in Little Endian order. It knows no schema; generated schema code and GesSchemaReader build on it. Reading allocates nothing.

GesBitWriter

Writes values of 0 to 64 bits into a caller's buffer in the bit order of the schema wire format: least significant bit first, bytes in Little Endian order. It knows no schema; generated schema code and GesSchemaWriter build on it. Writing allocates nothing.

GesBox

An axis-aligned box between two corners, without a unit. Creating one orders its corners, so Min is never above Max on an axis; a 2D box has Z 0 on both. Scripts see it as the external type :Box of GesGeometryLibrary.

GesBytecodeInstruction

One logical bytecode instruction: an opcode, a unit-and-flags byte, three 16-bit operand words and a 64-bit payload, encoded as 16 bytes in .gesb. The named properties are opcode-specific views of the same words; the in-memory layout does not define the encoding.

GesCodeSegment

The immutable CodeSegment (section 0x0010): the program's single linear instruction table of at most 65,535 instructions, each encoded as 16 bytes. A code address is the zero-based index of an instruction in this table.

GesDebugSymbol

Names one physical register over a half-open range of code addresses. Only explicit script parameters and locals are named; compiler temporaries are not.

GesDisc

A filled circle in the plane z = 0, without a unit: a centre and a radius. Creating one takes the radius's magnitude. A disc is valid with a finite centre in the plane and a finite radius; the operations of an invalid one give null, as GES operations give nothing for a domain failure. Scripts see it as the external type :Disc of GesGeometryLibrary.

GesExecutionResult

Provides an allocation-free summary of one host pump.

GesMessageArgument

One named value in an ordered message argument list.

GesPoint

A position with three Binary64 components and no unit, the native counterpart of a GES Point. A 2D point has Z 0. As in the language, a point moves by a GesVector, two points give a vector, and a point does not scale. The unit belongs to the schema or host and is applied when it converts to or from a GesValue.

GesProgramMetadataSegment

The immutable decoded ProgramMetadataSegment (section 0x0001) of a .gesb V1 program: module identity, program-level resource bounds and the application-owned program version.

GesPublishResult

Describes the independent local and outbound outcomes of one publish operation without allocating.

GesReadOnlyArray<T>

Immutable array view used by portable programs and other immutable API models.

GesSchemaBound

A bound, step or delta range: a parameter or an exact decimal.

GesSchemaDecoded

A decoded top-level value and the bytes it occupied.

GesSchemaDeltaDecoded

The sizes of a decoded delta.

GesSchemaDumpResult

The readable form of encoded data.

GesSchemaField

The handle of a field in a bound schema. Resolving it once makes further uses free of lookups.

GesSchemaReader

Decodes one top-level record or message without allocating on success. Data is untrusted: every limit is checked, and invalid data fails with a GesWireException. Fields are read in declaration order.

GesSchemaSource

A named schema source text.

GesSchemaWriter

Encodes one top-level record or message into a caller's buffer without allocating on success. Fields are written in declaration order; a nested schema, Point or Vector is entered with BeginNested(GesSchemaField).

GesSourceMapEntry

Maps a half-open range of code addresses to a range of UTF-8 bytes in one source.

GesStartResult

Describes completed initialization independently of queue idleness.

GesStringConstantSegment

The immutable StringConstantSegment (section 0x0002): an ordered pool of at most 65,535 strict UTF-8 strings that bytecode and bindings reference by zero-based ushort index. Order and duplicates are program data.

GesStringConstantSegment.SliceEntry

Locates one string entry inside Data.

GesUInt16IndexList

A read-only view of one list of a GesUInt16IndexListSegment, such as an argument register list or a message shape; it shares the segment's storage without copying.

GesUInt16IndexListSegment

The immutable UInt16IndexListSegment (section 0x0003): at most 65,535 ordered lists of ushort elements that bindings and instructions reference by zero-based list index. The referencing field or opcode defines what the elements mean, for example string indices of argument names and tags, or register lists.

GesUInt16IndexListSegment.SliceEntry

Locates one list inside Data.

GesVector

A displacement with three Binary64 components and no unit, the native counterpart of a GES Vector. A 2D vector has Z 0. The unit belongs to the schema or host that uses the value and is applied when it converts to or from a GesValue.

Interfaces

IGesClock

Supplies monotonic elapsed time to a serial host or a network end. Implementations must never move backwards.

IGesExtensionFunction

Synchronous host callback that implements one extension function.

IGesExtensionRegistry

Resolves the host's extension functions for the extension imports of a Program while Host.Load links it; it is not consulted per invocation.

IGesExternalTypeCatalog

Declarative compile-time description of the external types a host offers: names, fields and constructor signatures, without constructors, field accessors or host instances.

IGesExternalTypeConstructor

Host implementation of one declared external type constructor.

IGesExternalTypeRegistry

Resolves the host's external type constructors for the constructor imports of a Program while Host.Load links it; it is not consulted per call.

IGesExternalValue

A host object exposed to scripts as a value of a declared external type. The runtime keeps no field values: every script field read calls GetField(string) again, and every conversion to Map, JSON or schema encoding reads all declared fields in declaration order.

IGesNativeMessageHandler

Portable synchronous message handler invoked by a GameEventScriptHost.

IGesProfiler

Optional synchronous instrumentation factory. Callbacks must not throw or reenter a host. Timing, allocation and report policies belong to the embedding. Instances require serialized access.

IGesProgramProfiler

Instruction-boundary callbacks for one loaded instance. Callbacks must not throw, pump a host, or modify execution. No callback is made while the host waits between slices.

IGesPublishSink

Receives synchronous outbound publications after the host has attempted local enqueue.

IGesRuntimeObserver

Observes synchronous host behavior without participating in dispatch. Implementations must not throw and must not recursively pump the observed host. Every queued emit, processed publish, received message, delayed send and initialization message carries a host-local send ID: it starts at 1, increases by one per such send and is reported by every callback about that send, from emit, publish or scheduling to each dispatch or discard. 0 reports a send without an ID. Every callback has an empty default implementation, so an observer implements only the callbacks it needs.
