Interface IGesRuntimeObserver

Namespace
GameEventScript.Api
Assembly
GameEventScript.Runtime.dll

Observes synchronous host behavior without participating in dispatch. Implementations must not throw and must not recursively pump the observed host. Every queued emit, processed publish, received message, delayed send and initialization message carries a host-local send ID: it starts at 1, increases by one per such send and is reported by every callback about that send, from emit, publish or scheduling to each dispatch or discard. 0 reports a send without an ID. Every callback has an empty default implementation, so an observer implements only the callbacks it needs.
