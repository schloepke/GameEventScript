Class GesNetworkConnection

Namespace
GameEventScript.Network

One side of a network session: a synchronous state machine without threads, sockets or clocks. The host passes received bytes and the current time, takes events and takes packets to transmit. Times are microseconds of a monotonic clock chosen by the host. Not thread-safe; one caller at a time.

CanReceive

Gets whether Receive(ReadOnlySpan<byte>, long) takes further bytes. On a stream or message transport it is false while the frame bucket holds less than one frame, after the frames received drew it down; leave the bytes unread until Advance(long) refilled the bucket, which NextDeadline includes. Always true on a datagram transport.

Receive(ReadOnlySpan<byte>, long)

Passes received bytes: one packet on a message transport, any chunk of the byte stream on a stream transport. The connection first advances to now. Errors close the connection with their code; once closed, received bytes are ignored. On a stream or message transport, bytes passed while CanReceive is false close the connection with network.rateExceeded.
