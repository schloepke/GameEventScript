ExecuteFrame(int)

Synchronously advances the serial host by at most the supplied number of script opcodes.

public GameEventScriptExecutionResult ExecuteFrame(int opcodeBudget)

Parameters

opcodeBudget int

The positive scheduler budget for this call. Native handlers remain atomic and do not consume opcode units.

Returns

GameEventScriptExecutionResult

A value-type summary of work performed and the resulting host state.

Remarks

The caller must serialize access to a host. A handler may enqueue and change future subscriptions, but must not recursively pump this host.

Exceptions

InvalidOperationException

The host is not ready or is already executing a callback.

ArgumentOutOfRangeException

Thrown when opcodeBudget is not positive.

Load(GameEventScriptProgram, int)

Validates and links an immutable program into this host and registers all of its handlers.

public GameEventScriptInstance Load(GameEventScriptProgram program, int priority = 0)

Parameters

program GameEventScriptProgram

The portable program to load. The program remains reusable by other hosts.

priority int

The dispatch priority shared by the program's handlers. Higher values run first; equal priorities retain registration order.

Returns

GameEventScriptInstance

A host-local instance handle that can detach the program.

Remarks

Loading is atomic. When initialization needs a queue slot, capacity is checked before any host registration or VM preparation. A full queue rejects loading with the link diagnostic link.initializationQueueFull; the unchanged host can retry after pending messages are processed.

Exceptions

InvalidOperationException

The initial start failed, or loading was called reentrantly from startup or script execution.

ArgumentNullException

Thrown when program is null.

GameEventScriptProgramFormatException

Thrown when the program is structurally or semantically invalid.

GameEventScriptDynamicLinkException

Thrown when runtime bindings are unavailable, the program exceeds host limits, or its initialization cannot fit in the queue.

Start()

Initializes the complete initial load group in load order without dispatching ordinary messages.

public GameEventScriptStartResult Start()

Returns

GameEventScriptStartResult

The shared startup outcome. Repeated calls return the original result without running initialization again.

Remarks
