An immutable GES value: Nothing, a number with optional quantity unit, Boolean, Text, Tag, Vector, Point, Dice, Bytes, List, Map, Record, external value, Range, Series, Message or Handler. Equality is strict and structural.

Remarks

Explicit V1 value JSON transport with the same limits as message JSON. Decoding never executes constructors.
