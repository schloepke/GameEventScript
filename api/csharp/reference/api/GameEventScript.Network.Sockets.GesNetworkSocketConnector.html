Class GesNetworkSocketConnector

Opens the TCP, WebSocket or UDP transport of a client end. Opening runs in the background: the end's first poll starts it, packets wait for it, and a failure to open ends the transport, so the connection closes with network.transportClosed. One connector serves one client end.
