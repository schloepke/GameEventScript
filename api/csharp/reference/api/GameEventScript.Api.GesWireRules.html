Class GesWireRules

Namespace

The value rules of the schema wire format over plain operands: Text and tag validity, the exact quantization of a step p / 10^k and wrapping. Generated schema code calls them with constant operands, and the interpreted writer and reader use the same rules, so both encode identical bytes.
