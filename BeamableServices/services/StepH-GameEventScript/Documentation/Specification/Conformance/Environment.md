# Conformance environment specification

> [!IMPORTANT]
> **Structural draft.** This document owns the normative portable conformance environment but is not yet complete.

## Scope

This specification defines capability identities, fixed extension operations, external types, native handlers, publish sinks, observers, resource resolution, limits, performance profiles, and prohibited implementation-specific behavior.

Runner behavior belongs to [Runner](Runner.md). Authored test syntax belongs to [Markdown format](MarkdownFormat.md).
