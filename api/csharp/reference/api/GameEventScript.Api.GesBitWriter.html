Struct GesBitWriter

Writes values of 0 to 64 bits into a caller's buffer in the bit order of the schema wire format: least significant bit first, bytes in Little Endian order. It knows no schema; generated schema code and GesSchemaWriter build on it. Writing allocates nothing.

Remarks

Bits are collected in a 64-bit word that is stored once it is full, so a buffer of the record's byte count suffices; a full buffer fails with wire.bufferTooSmall. The writer must not be copied while it is used, since each copy holds its own pending bits.
