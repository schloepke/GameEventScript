Small language. Clear boundaries.

Fits inside your game.

01

Messages connect the pieces

Handlers react to named messages and emit new ones. Your application supplies native actions, data and the starting event.

02

State stays with you

Script values are immutable. Your application owns persistent state and decides what scripts can see through explicit native bindings.

03

A shared contract

C# and Swift implement the same language and portable program format, checked against a shared Markdown conformance corpus.

Schemas, documents and generated code

Data that fits the wire.

Describe your data once. Get exact bit-level encoding for the network, checked data files for your content and typed code for C# and Swift.

Sender and receiver share the schema. Its hash tells them they do.

01

Schemas .gess

Ranges, steps and units decide the bits of every field. Packed records fit in one machine word, and deltas send only what changed since the last full record.

Describe data with schemas →
02

Documents .gesd

Write configuration and content with GES literals and comments. A schema checks every file and reports each error with its line and column.

Read the document format →
03

Generated code

ges schema generate writes typed wire records and models for C# and Swift. Both produce the same bytes, without allocations on the hot path.
