# Host runtime specification

> [!IMPORTANT]
> **Structural draft.** This document owns the normative host and execution state machine but is not yet complete.

## Scope

This specification defines Host construction, Program loading, Instance and Subscription lifecycle, Receive, Emit, Publish, queue snapshots, handler ordering, frame execution, run-to-completion execution, runtime limits, Context behavior, observation, errors, and native-handler interaction.

Program transport data belongs to [Program model](ProgramModel.md). VM instructions belong to [Bytecode](Bytecode.md). API surface and ownership terminology belong to [Public API](PublicApi.md).
