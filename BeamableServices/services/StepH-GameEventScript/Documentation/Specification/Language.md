# Game Event Script language specification

> [!IMPORTANT]
> **Structural draft.** This document owns the normative language definition but is not yet complete.

## Scope

This specification defines lexical grammar, tokens, syntax, declarations, scopes, types, expressions, statements, handlers, functions, predicates, collections, pipelines, randomness, and message operations.

Exact Unicode behavior belongs to [Text semantics](Semantics/Text.md), numeric behavior to [Number semantics](Semantics/Numbers.md), and seeded randomness and stable ordering to [Determinism](Semantics/Determinism.md). Runtime hosting and delivery behavior belongs to [Host runtime](HostRuntime.md).
