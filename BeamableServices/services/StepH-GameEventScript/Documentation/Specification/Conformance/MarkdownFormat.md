# Conformance Markdown format specification

> [!IMPORTANT]
> **Structural draft.** This document owns the normative portable conformance authoring format but is not yet complete.

## Scope

This specification defines UTF-8 Markdown structure, YAML frontmatter and semantic blocks, suite and case identity, inheritance, source grouping, ordered step tables, expectations, performance profiles, bytecode snapshots, source ranges, and parser limits.

Execution belongs to [Runner](Runner.md). Runtime fixtures and capabilities belong to [Environment](Environment.md). Cross-port acceptance belongs to [Cross-language acceptance](CrossLanguageAcceptance.md).
