Class GesNetworkServerEnd

Namespace
GameEventScript.Network

The server end of a session: it accepts clients from an acceptor, owns one server connection per client and drives all of them from Poll<THandler>(ref THandler). Clients have stable end-local ids. Publishes and ticks reach every client. One caller at a time; not thread-affine.

Poll<THandler>(ref THandler)

Accepts every waiting client, passes received packets to every connection, hands every event to the handler and transmits every due packet. A connecting client is accepted after its event unless the handler accepted or refused it, also when the handler throws; after the handler closes or refuses a client, that client's remaining events up to its disconnect are skipped, and a closed client leaves the end after its event. Never blocks and never calls the handler outside this call.
