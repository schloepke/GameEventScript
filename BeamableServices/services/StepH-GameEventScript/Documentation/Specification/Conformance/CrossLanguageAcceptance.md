# Cross-language conformance acceptance

> [!IMPORTANT]
> **Structural draft.** This document owns the normative acceptance contract for language ports but is not yet complete.

## Scope

This specification defines authored-corpus identity, stable case matching, capability disclosure, optional skips, result exchange, required pass conditions, fixture identity, and acceptance evidence for C#, Swift, Kotlin, C++, and Unity integrations.

Result production belongs to [Runner](Runner.md). Capabilities and fixtures belong to [Environment](Environment.md). Test authoring belongs to [Markdown format](MarkdownFormat.md).
