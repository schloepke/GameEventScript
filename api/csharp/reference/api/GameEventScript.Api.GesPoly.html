A closed polygon in the plane z = 0, without a unit: its points in order, the last connecting to the first. A polygon is valid with at least three finite points in the plane, no edge of zero length, no two edges that cross or overlap, and an area other than zero; the operations of an invalid one give null, as GES operations give nothing for a domain failure. Scripts see it as the external type :Poly of GesGeometryLibrary.
