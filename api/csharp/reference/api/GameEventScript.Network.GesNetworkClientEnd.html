Class GesNetworkClientEnd

The client end of a session: it owns one client connection and its transport and drives both from Poll<THandler>(ref THandler). Sends, publishes and ticks made before the session is established wait in the end and reach the connection when it connects. One caller at a time; not thread-affine.

Poll<THandler>(ref THandler)

Opens the transport on the first call, passes received packets to the connection, hands every event to the handler and transmits every due packet. After the handler closes the connection, its remaining events up to the disconnect are skipped. Never blocks and never calls the handler outside this call.
