The immutable StringConstantSegment (section 0x0002): an ordered pool of at most 65,535 strict UTF-8 strings that bytecode and bindings reference by zero-based ushort index. Order and duplicates are program data.

Remarks

All entries share one contiguous byte buffer, Data, addressed by Slices. A default instance is an empty pool on which every index is invalid.
