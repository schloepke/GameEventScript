Class GesSchemaValues

Namespace
GameEventScript.Api
Assembly
GameEventScript.Runtime.dll

The convenient path between GES values and the wire, for rare data. A Record or Map encodes by field name, and fields without a schema entry, such as computed fields, are not transmitted. Only a Map that selects a union alternative must have a field for each of its keys. Time-critical code uses GesSchemaWriter and GesSchemaReader.
