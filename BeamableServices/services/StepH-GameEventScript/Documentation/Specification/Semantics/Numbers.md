# Portable number semantics

> [!IMPORTANT]
> **Structural draft.** This document owns the normative numeric contract but is not yet complete.

## Scope

This specification defines signed 64-bit integers, IEEE-754 Binary64 values, units, arithmetic, overflow, division, remainder, conversion, rounding, non-finite values, serialization spelling, and runtime numeric equality.

Operator syntax belongs to [Language](../Language.md). Numeric opcode behavior links to this contract from [Bytecode](../Bytecode.md).
