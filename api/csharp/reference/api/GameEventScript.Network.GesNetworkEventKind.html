The kind of a connection event.

public enum GesNetworkEventKind

Fields

Closed = 4

The connection closed.

Connected = 2

The session is established.

Connecting = 1

A client asks to connect; the payload is its token. Server only.

Message = 3

A complete message arrived on a route.

None = 0

No event is pending.

Tick = 7

A tick is complete: the message events of its changed members precede it. TickNumber tells its number.

TransferCancelled = 6

A transfer was cancelled by this side, by its host or by the peer; the session continues.

TransferProgress = 5

A transfer on a bulk route advanced: the receiver got more of its bytes, or the peer confirmed more of the bytes sent.
