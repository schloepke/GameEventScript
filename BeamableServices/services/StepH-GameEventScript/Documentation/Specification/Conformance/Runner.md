# Conformance runner specification

> [!IMPORTANT]
> **Structural draft.** This document owns the normative conformance execution and result contract but is not yet complete.

## Scope

This specification defines synchronous case, document, and corpus execution; capability handling; pass, fail, skip, and error classification; immutable results; canonical JSON; aggregate Markdown reports; performance measurement; and received approval candidates.

Input syntax belongs to [Markdown format](MarkdownFormat.md). Environment-provided behavior belongs to [Environment](Environment.md). Port acceptance belongs to [Cross-language acceptance](CrossLanguageAcceptance.md).
